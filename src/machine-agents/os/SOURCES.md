# Machine icons

The sidebar shows each machine's operating system or Linux distribution with one of these icons.

- `windows.svg` is drawn for harns: four panes, as Windows' mark.
- All the others are [Simple Icons](https://simpleicons.org) 16.20.0, CC0 1.0. They are fetched unchanged from
  `https://cdn.jsdelivr.net/npm/simple-icons@16.20.0/icons/<name>.svg`. The marks are their owners' trademarks,
  shown only to name the system a machine runs.
